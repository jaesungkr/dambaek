# 조건부 패턴: 덜어낼 때와 남길 때

표현 하나로 좋은 글과 나쁜 글을 구분하지 않는다. 아래 문구와 예문은 담백을 위해 새로 작성한 설명용 예시다. 정답 문자열이나 치환 목록으로 쓰지 않는다.

## 1. 부정과 대조

**확인:** 실제 제한이나 오해를 막는가, 아무 주제에나 붙는 말인가?

- 덜어내기: “색상을 바꿀 수 있다. 하지만 인생의 모든 문제를 해결하지는 않는다.” → “색상을 바꿀 수 있다.”
- 남기기: “색상을 바꿀 수 있지만 인쇄물에는 적용되지 않는다.” → 그대로 둘 수 있다.
- 장르 예외: “네 탓이라는 뜻은 아니야”는 관계 메시지에서 중요한 범위를 정한다. 필요 없는 면책으로 단정하지 않는다.

## 2. 가능 표현과 부탁

**확인:** 무거운 명사형인가, 권한·가능성·정중함을 전달하는가?

- 다듬기: “예약의 취소를 진행하는 것이 가능합니다.” → “예약을 취소할 수 있습니다.”
- 남기기: “가능하시면 오늘 확인해 주실 수 있을까요?” → 선택 가능한 부탁의 강도를 유지한다.
- 주의: “취소될 수 있다”를 “취소된다”로, “부탁드린다”를 “해야 한다”로 바꾸지 않는다.

## 3. 접속어와 추가 조건

**확인:** 관계를 설명하지 않는 반복인가, 조건이 누적되는가?

- 다듬기: “메뉴를 열었다. 또한 설정을 눌렀다. 또한 알림을 껐다.” → “메뉴를 열고 설정에서 알림을 껐다.”
- 남기기: “승인이 필요하다. 또한 원본 파일도 제출해야 한다.” → 두 요구를 모두 남긴다. “승인 또는 원본 파일”로 바꾸면 안 된다.
- 주의: 순서를 압축하면서 실제 작업 단계나 인과를 지우지 않는다.

## 4. 반복과 감정의 리듬

**확인:** 같은 정보만 재설명하는가, 반복이 감정이나 장면을 만드는가?

- 다듬기: “결과는 한 시간 뒤에 나왔다. 결과가 나오기까지 걸린 시간은 한 시간이었다.” → “결과는 한 시간 뒤에 나왔다.”
- 남기기: “문을 두드렸다. 한 번 더 두드렸다.” → 반복된 행동을 한 번으로 줄이지 않는다.
- 장르 예외: 에세이와 개인 메시지의 반복·웃음·강조는 정보 중복만으로 판단하지 않는다.

## 5. 명사형과 정확한 용어

**확인:** 동사를 불필요하게 늘였는가, 고유한 기술 의미인가?

- 다듬기: “주소의 변경을 진행했습니다.” → “주소를 변경했습니다.”
- 남기기: “변경 감지 기능을 껐다.” → 기능명인 ‘변경 감지’를 일상어로 억지로 바꾸지 않는다.
- 주의: 능동문을 만들려고 알 수 없는 행위자를 추가하지 않는다.

## 6. 도입·맺음과 관계

**확인:** 본문과 무관한 틀인가, 독자와의 관계나 글의 여운에 필요한가?

- 다듬기: “다양한 선택지가 있는 시대에 선택은 중요합니다. 오늘은 두 요금제를 비교합니다.” → “두 요금제를 비교합니다.”
- 남기기: “잘 지내셨어요? 지난번에 도와주셔서 감사했어요.” → 편지에서 의미 있는 안부와 감사일 수 있다.
- 주의: 모든 글에 핵심 결론, 실용 팁, 표, 후속 약속을 넣지 않는다.

## 참고한 접근과 적용 범위

외부 프로젝트 [im-not-ai](https://github.com/epoko77-ai/im-not-ai)(조사 시 v2.4.7)의 조건부 패턴·장르 예외·검증 분리라는 접근을 참고했다. 구체적인 한국어 규칙과 예문은 담백의 의미 보존 원칙에 맞춰 독자적으로 작성했다. 외부 프로젝트의 표현을 금칙어로 옮기거나 그 프로젝트의 평가 결과를 담백의 성능 근거로 사용하지 않는다. 담백의 실제 검토 범위는 `tests/`의 기록을 따른다.
