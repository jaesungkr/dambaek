# 담백 · Dambaek

[English](README.md) | **한국어**

담백은 글쓴이의 뜻과 말투를 살리면서 어색한 한국어 문장을 다듬는 AI 편집 지침입니다.

## 설치

### Claude Code

Claude Code 대화 입력창에서 아래 두 명령을 차례대로 실행하세요. Node.js를 업데이트할 필요는 없습니다.

```text
/plugin marketplace add jaesungkr/dambaek
/plugin install dambaek@dambaek
```

새 세션에서 `/dambaek:dambaek draft.md의 도입부를 다듬어 줘`를 입력하세요.

### Codex

**Node.js 22.20.0 이상**에서 프로젝트 폴더의 터미널에 다음 명령을 입력하세요.

```sh
npx --yes skills@1.9.0 add jaesungkr/dambaek --skill dambaek -a codex -y
```

같은 프로젝트에서 Codex를 열고 `$dambaek draft.md의 도입부를 다듬어 줘`를 입력하세요.

### Claude.ai와 Claude Desktop 일반 채팅

[dambaek-chat.zip](https://github.com/jaesungkr/dambaek/releases/download/v0.1.0/dambaek-chat.zip)을 내려받으세요. **Customize → Skills → + → Create skill → Upload a skill**에서 압축을 풀지 않은 채 업로드하고 담백을 켜세요. 채팅에 한국어 초안을 붙여 넣고 다듬어 달라고 요청하세요. Claude의 코드 실행·파일 생성 기능이 필요하며, 로컬 Node.js 업데이트는 필요하지 않습니다.

ZIP SHA-256: `2bb9709f93cb16ee5d055766ddb484334af9973d37a420cd6f13ab65820c7048`

**Codex와 Claude Code의 파일 미리보기**

두 도구 모두 “draft.md의 도입부를 자연스러운 한국어로 다듬어 줘”처럼 요청할 수 있습니다. 대화에서 수정안을 확인하고, 파일에 쓰려면 “방금 제안한 도입부만 파일에 반영해 줘”라고 요청하세요.

**다듬기 전**

> 모임 장소는 2층 강의실입니다. 다만 토요일에는 2층 강의실을 쓸 수 없어서 토요일 모임은 1층 도서실에서 엽니다.

**다듬은 뒤**

> 모임 장소는 2층 강의실입니다. 토요일에는 강의실을 쓸 수 없어 1층 도서실에서 모입니다.

## 줄여 써도 뜻이 달라지지 않도록

- **관찰 횟수.** “오전과 오후에 수달을 봤다”는 두 번 봤다는 뜻입니다. 같은 수달을 두 번 봤을 수도 있습니다.
- **‘만’의 위치.** “민지가 사진만 보냈다”는 민지가 보낸 게 사진뿐이라는 뜻입니다. “민지만 사진을 보냈다”는 사진을 보낸 사람이 민지뿐이라는 뜻입니다.
- **자료로 확인한 사실.** 공지에 날짜가 없다고 해서 행사 날짜가 아직 정해지지 않았다고 쓸 수는 없습니다.

이름과 수치, 인용, 글쓴이의 의견과 망설임도 원문에 맞게 남깁니다. 별도 요청이 없으면 제목과 표, 링크, 코드를 그대로 두고, 짧은 메시지에 서론이나 결론을 덧붙이지 않습니다.
