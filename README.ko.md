# 담백 · Dambaek

[English](README.md) | **한국어**

담백은 AI로 한국어 글을 다듬을 때 쓰는 편집 지침입니다. 블로그 글이나 소개글에서는 번역투와 반복을 덜어냅니다. 이메일에서는 부탁의 강도와 높임말을, 일상 메시지나 감상문에서는 글쓴이의 말투와 감정을 살립니다.

## 사용법

평소 쓰는 AI에 [SKILL.md](SKILL.md)의 내용과 다듬을 글을 함께 붙여 넣으세요. 별도 앱이나 담백 전용 API 키는 필요 없습니다. 아래처럼 고치고 싶은 부분을 짚어 주면 됩니다.

> 이 문단에서 반복되는 설명을 줄여 줘. 수치와 인용은 그대로 두고, 어디를 왜 고쳤는지도 알려 줘.

수정본을 읽을 때는 원래의 사실과 조건, 말투가 그대로인지 확인하세요. 같은 지침을 자주 쓴다면 도구에 맞춰 저장해 둘 수 있습니다.

| 도구 | 지침을 다시 쓰는 방법 |
| --- | --- |
| ChatGPT | 프로젝트 자료에 지침 파일을 올리고, 프로젝트 지침에 “한국어 글을 다듬을 때 담백을 참고해 줘”라고 적으세요. |
| Claude | 사용자 스킬로 설치하려면 `SKILL.md`와 `references/`가 들어 있는 `dambaek` 폴더를 ZIP으로 묶어 업로드하세요. |
| Notion AI | 지침을 페이지에 저장한 뒤 편집을 요청할 때 그 페이지를 지정하세요. AI가 페이지를 읽을 수 없으면 지침을 직접 붙여 넣으세요. |

[도구별 사용 안내](docs/platforms.md)에 공식 문서를 바탕으로 정리한 설정 방법과 이용 조건이 있습니다. 각 제품에서 설정부터 편집까지 이어지는 과정은 아직 확인하지 못했습니다.

## 문장을 어떻게 다듬나요?

**다듬기 전**

> 이번 글에서는 새롭게 출시된 모델의 문서 작성 기능에 대해 자세히 알아보겠습니다. 하지만 모든 문제를 해결하는 만능 도구는 아닙니다.

**다듬은 뒤**

> 새 모델의 문서 작성 기능을 살펴보겠습니다.

무엇을 소개하는지 첫 문장에서 바로 알 수 있습니다. “PDF 내보내기를 지원하지 않는다”처럼 독자에게 필요한 제약이 있었다면 그 내용은 남깁니다.

문단 안에서 같은 설명이 되풀이되면 한 문장으로 합칩니다. 문장을 이을 때는 원문에 드러난 관계를 따릅니다. 연결어나 어미가 겹쳐도 읽기 편하면 그대로 둡니다. 긴 대시가 자주 나오면 문장에 맞게 하이픈이나 쉼표를 쓰거나 문장을 나눕니다. 굵은 글씨는 강조할 곳에만 남깁니다.

## 줄여 써도 뜻이 달라지지 않도록

- **관찰 횟수.** “오전과 오후에 수달을 봤다”는 두 번 봤다는 뜻입니다. 같은 수달을 두 번 봤을 수도 있습니다.
- **‘만’의 위치.** “민지가 사진만 보냈다”는 민지가 보낸 게 사진뿐이라는 뜻입니다. “민지만 사진을 보냈다”는 사진을 보낸 사람이 민지뿐이라는 뜻입니다.
- **자료로 확인한 사실.** 공지에 날짜가 없다고 해서 행사 날짜가 아직 정해지지 않았다고 쓸 수는 없습니다.

이름과 수치, 인용, 글쓴이의 의견과 망설임도 원문에 맞게 남깁니다. 별도 요청이 없으면 제목과 표, 링크, 코드를 그대로 두고, 짧은 메시지에 서론이나 결론을 덧붙이지 않습니다.
